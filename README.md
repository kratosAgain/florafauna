# Flora Fauna Website

A simple static landing page for the Flora Fauna / Giver-Mover-Judge marketplace concept.

## Files

- `index.html` - the website page
- `styles.css` - visual styling and responsive layout
- `script.js` - small reveal animation
- `assets/agent-flow.svg` - visual diagram

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open Settings -> Pages.
4. Set the source to `Deploy from a branch`.
5. Choose the `main` branch and `/root`, then save.

GitHub will provide a public URL after the site builds.
